# CCTV Inspection Marina v1

Three roles: Security Supervisor, CCTV Monitor, Administration.
Workflow: New Request -> Under CCTV Review -> Review Completed -> Closed.
Demo: security/security123, cctv/cctv123, admin/admin123.
Run: pip install -r requirements.txt && python app.py
Deployment root must contain app.py, templates/, static/, requirements.txt.
